## Must Haves

**Truths:**
- All numeric inputs use QDoubleSpinBox/QSpinBox (not QLineEdit)
- Frequency locked to 10-50 kHz range
- Workpiece radius must be < coil inner radius
- Run button only enabled when all inputs valid

**Prohibitions:**
- MUST NOT use QLineEdit for numeric input (use QDoubleSpinBox)
- MUST NOT allow frequency outside 10-50 kHz
- MUST NOT allow workpiece larger than coil inner radius
- MUST NOT run calculation with invalid inputs

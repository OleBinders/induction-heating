## Must Haves

**Truths:**
- All properties in a snapshot are at the same temperature
- Properties are physically reasonable (positive values, μᵣ ≥ 1.0)
- Pipeline uses consistent properties for all calculations at a given temperature

**Prohibitions:**
- MUST NOT mix properties from different temperatures in a single calculation
- MUST NOT allow negative resistivity, specific heat, or thermal conductivity
- MUST NOT allow permeability < 1.0

<task>
<type>feature</type>
<description>Create sigmoid-based Curie transition model as fallback for materials without detailed data</description>
<read_first>
- /home/olebinders/Documents/Code/Induction Heating/.planning/phases/03-temperature-dependent-properties-curie-transition/03-RESEARCH.md
- /home/olebinders/Documents/Code/Induction Heating/.planning/research/PITFALLS.md
</read_first>
<acceptance_criteria>
- Function: permeability_sigmoid(T, mu_r_0, Tc, k) → μᵣ(T)
- Formula: μᵣ(T) = 1 + (μᵣ₀ - 1) / (1 + exp(k * (T - Tc)))
- Guaranteed to stay ≥ 1.0 for all T
- Smooth transition (C∞ continuous)
- k parameter controls transition steepness (default: k = 0.1 for ~20°C transition width)
</acceptance_criteria>
<verify>
- At T = Tc: μᵣ = 1 + (μᵣ₀ - 1) / 2 (midpoint of transition)
- At T ≪ Tc: μᵣ ≈ μᵣ₀
- At T ≫ Tc: μᵣ ≈ 1.0
- Derivative is continuous everywhere
</verify>
</task>

<task>
<type>feature</type>
<description>Create polynomial Curie transition model as alternative</description>
<read_first>
- /home/olebinders/Documents/Code/Induction Heating/.planning/phases/03-temperature-dependent-properties-curie-transition/03-RESEARCH.md
</read_first>
<acceptance_criteria>
- Function: permeability_polynomial(T, mu_r_0, Tc, T_start, n) → μᵣ(T)
- Formula: μᵣ(T) = 1 + (μᵣ₀ - 1) * (1 - ((T - T_start) / (Tc - T_start))^n) for T_start < T < Tc
- μᵣ(T) = μᵣ₀ for T ≤ T_start
- μᵣ(T) = 1.0 for T ≥ Tc
- n parameter controls transition shape (default: n = 2 for quadratic)
</acceptance_criteria>
<verify>
- At T = T_start: μᵣ = μᵣ₀
- At T = Tc: μᵣ = 1.0
- At T < T_start: μᵣ = μᵣ₀ (constant)
- At T > Tc: μᵣ = 1.0 (constant)
</verify>
</task>

## Must Haves

**Truths:**
- Permeability always ≥ 1.0 (never drops below paramagnetic)
- Transition is smooth (no discontinuities that cause numerical instability)
- Data-driven interpolation takes precedence over model-based when data is available

**Prohibitions:**
- MUST NOT allow permeability < 1.0
- MUST NOT use step function for Curie transition (causes numerical instability)
- MUST NOT extrapolate beyond data range for data-driven method

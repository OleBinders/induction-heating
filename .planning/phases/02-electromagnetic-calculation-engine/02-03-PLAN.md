<acceptance_criteria>
- Function: eddy_current_density(B_surface, frequency, resistivity, radius, radial_positions) → J(r)
- For a/δ > 4 (thick workpiece): J(r) = J_surface * exp(-(a-r)/δ)
- For a/δ ≤ 4: use Bessel function solution J(r) = J_surface * J₀(kr)/J₀(ka)
- Automatically selects appropriate formula based on a/δ ratio
- J_surface computed from B_surface: J_surface = ωB_surface / (2ρ) * a (simplified)
- Returns current density in A/m²
</acceptance_criteria>
<verify>
- At surface (r=a), J = J_surface
- At center (r=0), J < J_surface (skin effect)
- For large a/δ, J drops exponentially from surface
- For small a/δ, J is more uniform across cross-section
</verify>
</task>

<type>feature</type>
<description>Implement power density calculation (Joule heating)</description>
<read_first>
- /home/olebinders/Documents/Code/Induction Heating/.planning/phases/02-electromagnetic-calculation-engine/02-RESEARCH.md
</read_first>
<acceptance_criteria>
- Function: power_density(J, resistivity) → p (W/m³)
- Formula: p(r) = J(r)² * ρ
- Function: total_power(J, resistivity, radius, length) → P_total (W)
- Integrates p(r) over workpiece volume: P = ∫₀ᵃ p(r) * 2πrL dr
- Uses numerical integration (scipy.integrate or trapezoidal rule)
- Returns power in Watts
</acceptance_criteria>
<verify>
- Power density is always positive (J²ρ ≥ 0)
- Total power increases with frequency (higher J)
- Total power increases with current (higher B, higher J)
- Power density peaks at surface, decreases toward center
</verify>
</task>
